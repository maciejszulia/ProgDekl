# ProgDekl

Declarative programming in Prolog: 10 labs and a team project.

University coursework from my Computer Science studies at UWM (2020–2024). I wrote the code by hand; the commit history is unchanged. This README was added in November 2026.

Years of work: 2023 (first commit on 24 April 2023, last commit on 10 June 2023).

## Contents

- `lab01/`–`lab10/`: Prolog programs, for example the blocks world (`klocki`), ancestors (`przodek.pl`), factorial (`silnia.pl`) and polynomials (`zad2-wielomian.pl`); the labs also hold screenshots, task documents and the submitted ZIP archives.
- `proj.pl`: the team project (May 2023), a Prolog program about perfumes.

## Running

The code needs SWI-Prolog, which this machine does not have, so I did not run it in November 2026.
